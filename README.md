# STUDY

Daily study tracker for DSA, System Design, SQL, and Machine Coding practice.

## How it works

- **6:00 AM IST** — GitHub Issue created with all 4 tracks' daily tasks
- **9:00 PM IST** — Reminder comment if tasks are still pending
- **Close the issue** anytime to mark the day complete and advance

## Tracks

| Track | Days | Content |
|-------|------|---------|
| DSA | 75 | 2 problems/day across 14 patterns, with LeetCode links |
| System Design | 29 | HLD + LLD topics |
| SQL | 30 | Progressive query challenges |
| Machine Coding | 20 | Backend, frontend, full-stack builds |

## Structure

```
.github/workflows/     — GitHub Actions (daily + night reminders, completion tracker)
study-plan/            — Curriculum JSON + progress tracker
DSA_PRACTICE/          — All study material, solutions, and notes
```
